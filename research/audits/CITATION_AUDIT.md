# FuturaMAX citation audit (R3, wave 1)

Summary: reachability and source-type breakdown of all 535 URLs cited by the six
external Deep Research runs, per run, plus every dead or damaged citation.
Keywords: citation audit, link check, 404, primary source share, bot-blocked, provider quality.
Read when: weighing how well-sourced a run is, or chasing a citation that will not open.
Current verdict: reachability is good; **reachability is not verification**. A 200 proves
the URL exists, not that the source says what the model claimed it says.
Status: GENERATED by tools/research/make_citation_audit.py - do not hand-edit.

## Known limitation of this audit

openwrt.org returns HTTP 200 with a bot-challenge body to plain urllib, so its `OK` rows
carry a challenge-page title rather than the real one. The OpenWrt device pages were read
through a real browser instead - see `knowledge/HARDWARE_MATRIX.md`, which is where the
first Grade-A target-hardware evidence in this project came from.
