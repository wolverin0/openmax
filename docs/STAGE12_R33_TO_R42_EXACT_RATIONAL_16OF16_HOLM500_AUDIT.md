## AD: statistical method and families

The [AD implementation](../analysis/statistics/fmx_r33_to_r42_exact_holm500_audit.py) and [bound result](../artifacts/autoresearch/waves_ac_to_af_20261024/wave_ad_exact_holm500_analysis.json) audit all45 within-round arm pairs across six outcomes, giving270 contrasts, plus ten pooled contrasts. Signed-rank tests remove exact zero differences, midrank absolute ties and count the full conditional sign distribution with integer generating polynomials. Sign tests use exact binomial tails. HL estimates use all Walsh averages. The95% and99.9% confidence sets invert exact tests at every Walsh breakpoint and intervening cell; sets may be unbounded or disconnected and are never replaced by an asymptotic interval or convex hull.

The n94 coefficient DP uses packed integer polynomial multiplication with a radix larger than all coefficients, so no carry changes a count; it does not enumerate2^94 sign assignments. Independent production tests compare all8931 n94 coefficients with the earlier scalar integer DP. Root review uses a separate scalar polynomial oracle and imports none of the numerical implementation under review. Exactness is conditional on the supplied finite float block differences; source-decimal subtraction is audited separately. One R42 totalgoodput p-value changes under that sensitivity (0.0041809082 to0.0039978027); no declared broad-family decision or five-outcome gate changes.
