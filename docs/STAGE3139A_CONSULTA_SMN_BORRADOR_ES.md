Asunto: Consulta sobre acceso automatizado a alertas SAT y ACP para Pergamino

Hola, somos un operador de conectividad de la zona de Pergamino, Buenos Aires.
Queremos usar alertas oficiales para posponer mantenimiento cuando haya riesgo
meteorologico, sin ofrecer un servicio publico de alerta ni reemplazar al SMN.

Podrian indicarnos un endpoint oficial gratuito, CAP o formato equivalente, para
consultar SAT y avisos a corto plazo por zona, junto con identificadores geograficos,
vigencia, actualizaciones/cancelaciones, frecuencia permitida y condiciones de uso
automatizado en un contexto comercial con atribucion al SMN?

Probamos de manera acotada el recurso publico `ws.smn.gob.ar/alerts/type/AL`
y recibimos HTTP 503. No asumimos que ese recurso sea una API documentada.
Tambien necesitamos saber si existe archivo historico de alertas por zona y horario
para contrastar incidentes propios sin datos personales.

Gracias. Quedamos a disposicion para adaptar la frecuencia de consulta y la
identificacion del cliente a sus requisitos.

Firma y contacto: completar por el operador antes de enviar.
