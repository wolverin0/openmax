1. **`sensitivity` (`.rodata` `0x5948`, `30` bytes = `5` bandwidths $\times$ `6` modulations, dBm)**:
   - `10 MHz`: `4096-QAM = -66 dBm`, `1024-QAM = -72 dBm`, `256-QAM = -78 dBm`, `64-QAM = -84 dBm`, `16-QAM = -88 dBm`, `QPSK = -90 dBm`
   - `20 MHz`: `4096-QAM = -63 dBm`, `1024-QAM = -69 dBm`, `256-QAM = -75 dBm`, `64-QAM = -81 dBm`, `16-QAM = -85 dBm`, `QPSK = -87 dBm`
   - `30 MHz`: `4096-QAM = -61 dBm`, `1024-QAM = -67 dBm`, `256-QAM = -73 dBm`, `64-QAM = -79 dBm`, `16-QAM = -83 dBm`, `QPSK = -85 dBm`
   - `40 MHz`: `4096-QAM = -59 dBm`, `1024-QAM = -65 dBm`, `256-QAM = -71 dBm`, `64-QAM = -77 dBm`, `16-QAM = -82 dBm`, `QPSK = -84 dBm`
   - `50 MHz`: `4096-QAM = -57 dBm`, `1024-QAM = -63 dBm`, `256-QAM = -69 dBm`, `64-QAM = -75 dBm`, `16-QAM = -81 dBm`, `QPSK = -83 dBm`

2. **`table_ptmpAPPwrRange` (`.rodata` `0x54c0`, `96` bytes = Low/High Band $\times$ `8` bandwidths $\times$ `6` modulations, dBm)**:
   - Low Band (`10..100 MHz`): `4096-QAM` target RSSI ranges from **`-66 dBm` (`10 MHz`)** to **`-60 dBm` (`40 MHz`)** and **`-52 dBm` (`100 MHz`)**.
   - High Band (`10..100 MHz`): `4096-QAM` target RSSI ranges from **`-65 dBm` (`10 MHz`)** to **`-59 dBm` (`40 MHz`)** and **`-55 dBm` (`100 MHz`)**.

### 5.5 Conducted TX Power Backoff Tables by MCS (`.rodata` `0x4e9c..0x55b0`)

> **Why `mcs_ceiling_toggle_txpwr` (`0x391b0`) Exists**: Because enabling `4096-QAM` (`12x`) forces a **`4.0 dB` conducted TX power reduction** relative to `1024-QAM` (`10x`) (`16.0 dBm` vs `20.0 dBm` on `LTU-Rocket`, and `10.0 dBm` vs `14.0 dBm` on `LTU-Lite`/`Pro`), `mcs_ceiling_toggle_txpwr` dynamically lowers/raises the PA power ceiling when `autoMcsCeiling` toggles `4096-QAM` (`radio.1.rate.auto_12x=enabled`).

## 6. LTU Runtime Control Plane (`af`, `ame_cfg.sh`, `ame_adj.sh`, `sysfs`, `debugfs`, Module Params)

### 6.1 Kernel INI Config Interface (`/sys/devices/platform/ame_ctrl_dev/config`)
`ame_config_handler` (`0x518` in `ame_dev.ko`, `10,336` bytes) parses INI blocks written via `ame_cfg.sh <SECTION> <key> <val>`:
- **`[SYS]`**: `ver`, `sys_mode` (`normal`/`test`), `role` (`ap`/`cpe`), `route` (`direct`/`direct2`/`direct0`/`indirect`), `net_mode` (`router`/`bridge`), `ext_switch_hw_en`, `wireless_mode` (`ptmp`/`ptp`), `ptmp_max_cpe` (`128`), `ssid`, `hw_addr`, `lockToApMac`, `l2_isolation`, `log_level`, `jumbo`, `ccode`, `board_ssid`, `board_hwrev`, `board_pcba`, `hfe_gmac`, `autolink_en`, `rf_align`, `hw_siso`, `NxN`.
- **`[RF]`**: `mimo`, `mcs_mode` (`0` = Fixed, `1` = Auto), `mcs` (`7, 11, 15, 19, 23, 31`), `bandwidth` (`10, 20, 30, 40, 50, 60, 80, 100`), `rf_mode`, `prefer_work_freq`, `prefer_work_txfreq`, `prefer_work_rxfreq`, `freq_list_enabled`, `auto_freq_list`, `auto_freq_mode`, `smart_scan`, `dhcp_snooping`, `freq`, `reg_obey`, `txgain`, `txpwr`, `recvTargetLvl`, `rx_target_pwr`, `rx_target_pwr_thr`, `rx_target_pwr_scan`, `rx_target_pwr_auto_en`, `dagc_target_pwr`, `rxgain` (`low`/`high`), `antenna_gain`, `antenna_id`, `cable_loss`, `autotxpwr`, `ofdma_en`, `ofdma_status`, `ofdma_subband_type`, `czlen`, **`autoMcsCeiling`** (`23` = `10x` ceiling, `31` = `12x` `4096-QAM` ceiling), `sync_mode`, `frame_offset`, `gps_sync_timeout`, `cpsample`, `duty_cycle` (`25..75`), `frame_len` (`1000, 2000, 2500, 4000, 5000` us), `dpd_param`, `pa_param`, `dl_symbols`, `ul_symbols`, `gap0`, `gap1`, `scatteredPilot`, `ofdma_start`, `ofdma_len`, `dfs_target_pwr`.
- **`[SECURITY]`**: `aes_en`, `wpa_key_mgmt` (`None`/`WPA-PSK`/`WPA-802.1X`), `cent_mgmt_dl_key_path`, `cent_mgmt_ul_key_path`, `wpa_anonymous_identity`, `wpa_identity`, `wpa_password`.

### 6.3 100 `/sys/devices/platform/ame_debug_dev/*` Attributes & 30 `/sys/kernel/debug/ame/*` Telemetry Dumps
- **Key Runtime Tuning Attributes in `/sys/devices/platform/ame_debug_dev/`**:
  - `autoMcsUpDown`: Reads/writes the 11-parameter rate-adaptation hysteresis vector (`mcsUpThreshold`, `mcsDownThreshold`, `mcsUpThreshold_timer`, `mcsDnThreshold_timer`, `mcsUpThrd_1024`, `cont1024Threshold`, `avgWeight`, `penaltyThreshold`, `penaltyTime`, `ackAccuulateCnt`, `smallTrafficTimer`).
  - `ldpc_iteration`: Adjusts hardware LDPC decoder iteration limit.
  - `snr_offset`: Reads/resets SNR boost offset (`ame_core_get_snr_boost` / `ame_core_set_snr_boost`).
  - `autopwr_en`, `autopwr_info`, `dlpwr_tune`, `ulpwr_tune`, `ulpwr_parm`, `ulpwr_cfg`, `ulpwr_enable`: Controls AP/CPE closed-loop ATPC and digital gain (`dgain`).
  - `ack_qpsk`, `first_qpsk`, `bd_rate`, `extra_pb`, `pgy_en`, `pgy_sched_en`, `local_sched_pre_assign_ctrl_en`, `bcq_en`, `bc_dl_symbols`, `air_limit`, `eth_limit`: Fine-grained OFDMA/TDMA scheduler symbol and airtime controls.
- **30 Debugfs Telemetry Nodes in `/sys/kernel/debug/ame/`**:
  `phy_regs`, `hcam`, `igmp`, `hfe`, `efinfo`, `qstatus`, `sched_mcs`, `ulmap`, `dlmap`, `analyzeFreqTxt`, `rate_ctrl`, `automcs`, `pwrctl`, `ptmp_mixmcs`, `mcs_dsb`, `auto_txpwr`, `bbp_dbg_log`, `scan_result`, `track_result`, `dl_latency`, `ul_sym_asgmt`, `bugt_cfg`, `bugt_cpe`, `sch_detail`, `isr_history`, `swq_record`, `hybrid`, `sch_qinfo`, `cir_record_dump`, plus `airtime`.
